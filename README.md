One brutally honest one-star review of the Moon — at most 120 characters,
written like a real angry reviewer, not a poem. The Moon runs our tides
without asking, ghosts us for days, then stares through the window at 3 AM.
Rude.

This is an entry by **RanSTAR ID** for make.fun's
["The Moon Gets One Star"](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5?ref=0m7x29es)
bounty ($2 in USDC, winner takes all).

## Run it

```bash
python3 main.py
```

It writes the single review to `/output/entry.txt` (creating `/output` if
needed). No dependencies, no network, deterministic — run it twice and you
get the same review.
